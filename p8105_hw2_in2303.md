line represents the physical subway line the subway route runs through,
such as the West End, or Jerome in the Bronx. station_name indicates the
name of a single station on the line. Each route column indicates
indicates what route is served, such as the Q train, or 4/5/6 trains. If
the station services less than 11 routes, the value is NA.
station_latitude / longitude indicates the location of the subway
station. entrance_type indicates the station’s entrance type. Entry
indicates whether or not the entrance type is also a point of entry. If
false, it is an exit. Vending indicates if there is a MTA card vending
machine at the entrance and ada notes whether or not it is ADA
(Americans with Disabilities Act) compliant. So far, I have told
`read_csv` to treat blank values as NA, cleaned the column names to be
all lower case and standardized with `janitor::clean_names()`, selected
the columns of interest with `select()`, and used the `mutate()`
function to transform the character variables in entry and vending to
logical variables. route8, 9, 10, and 11 column types were converted to
characters since they are subway route names.

### Problem 3

Importing and cleaning the MCI baseline dataset

``` r
mci_bsl = read.csv(
  "./data/MCI_baseline.csv",
  skip = 1,
  na = "."
  ) |>
  janitor::clean_names() |>
  mutate(
    sex = case_match(
      sex,
      1 ~ "male",
      0 ~ "female"),
    apoe4 = as.logical(apoe4)
    )

mci_bsl_tidy =
  mci_bsl |>
  filter(
    current_age < age_at_onset |
    is.na(age_at_onset)) |>
  mutate(
    id = as.character(id))
```

To clean the imported baseline dataset, first, we have to skip the first
row of the csv file usign `skip = 1`, since this row acts as a
dictionary for the columns, and is not relevant to anaylsis. Second, “.”
in the csv files was instructed to be treated as NA values. The sex
variable was tranformed to character variables “male” and “female”
instead of integers. apoe4, which notes APOE4 carrier status, was
changed to be a TRUE/FALSE logical variable. In order to filter for the
exclusion criteria, we must exclude study individuals that report MCI
before or at the same age as the current age of enrollment. So, the
`filter` function was used to keep individuals whose age at enrollment
was less than the age of MCI onset as well as those who did not have an
age of MCI onset recorded. 483 participants originally enrolled in the
study. Of the 483 participants, 4 were excluded from the study. From
this remaining cohort, 93 participants eventually developed MCI. After
exclusion, the average baseline age was 65.0286013 years and the
proportion of women in the study that are APOE4 carriers is 30% of them.
